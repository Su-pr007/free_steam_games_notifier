# Free Steam Games Notifier
Бот для уведомлений о бесплатных раздачах игр в Steam. Работает на Go и PostgreSQL в Docker.

## Локальная сборка
Для запуска нужен docker, чтобы в нём запустить бд. Для запуска:
```bash
docker compose up -d
```
Затем нужно применить миграции для бд:
```bash
go run cmd/migrate/main.go
```
После этого станет возможен запуск проекта:
```bash
go run cmd/bot/main.go
```

## Релиз
Для выкладывания проекта на сервер нужно собрать сервис в докер-образ и отправить в хранилище. На проекте используется ghcr.
Обе команды есть в Makefile, поэтому их можно запустить так:
```bash
make build
make push
```

На сервере в папке проекта выполняем команду для перезапуска продакшена:
```bash
make release
```
