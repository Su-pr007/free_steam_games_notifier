# Free Steam Games Notifier

## Планы
- [ ] Парсинг бесплатных игр из egs;
- [ ] Поддержание в бд актуального списка бесплатных игр. Сейчас старые игры не удаляются, а при появлении дублей возможен баг;
- [ ] Отслеживание отправленных уведомлений, чтобы появилась возможность отослать новым пользователям все необходимые сообщения;
- [ ] Удаление пользователя из бд.
